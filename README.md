# Kalpa Slideshow Generator

Internal AI-assisted presentation generator for Kalpa Inc.

## Vision
Build the world's best AI-powered business presentation generator that produces beautiful, editable PowerPoint and Google Slides decks.

## Phase 1
- Kalpa design system
- Brand asset library
- Six presentation template families
- JSON slide schema
- AI generation pipeline
- Native editable exports

## Approved design direction
- Clear storytelling
- Professional business aesthetic
- Creative layouts using shapes, icons, diagrams and imagery
- Kalpa blue-first palette with navy, peach and orange accents
- Editable outputs only
